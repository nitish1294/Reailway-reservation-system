# Railway Reservation System

## Overview

The Railway Reservation System is a web application designed to facilitate the booking of train tickets online. It allows users to search and view train details, while admins can add, update, and delete train information. This project is developed using HTML, CSS, JavaScript, JSP, Servlets, Maven, and JDBC.

## Features

- **User Features:**
  - Search for available trains.
  - View train details.
  - Register and log in to the system.

- **Admin Features:**
  - Add new train information.
  - Update existing train details.
  - Delete train information.

## Technologies Used

- **Frontend:**
  - HTML
  - CSS
  - JavaScript

- **Backend:**
  - JSP (JavaServer Pages)
  - Servlets
  - JDBC (Java Database Connectivity)

- **Build Tools:**
  - Maven

## Project Structure

- `index.html` - Main page for the website.
- `index-mobile.html` - Mobile view version of the main page.
- `login.jsp` - Login page for users.
- `register.jsp` - Registration page for new users.
- `src/` - Contains Java source files for Servlets and other backend functionalities.
- `WEB-INF/` - Contains configuration files and JSP pages.
- `pom.xml` - Maven configuration file.
